# 超声区域麻醉教材：出版社电子入口核查

核查日期：2026-10-27。本分工补充核查 Springer Tsui 图谱与 Cambridge 实用教材，避免重复主线程已查的 Gray／Hadzic。只读出版社书页、目录及官方短试阅；未购买、登录机构、下载整书、取得付费章节或更改模型。

## 与当前三维工作衔接

合法阅读电子书可以为候选原网格的出口、分支与相邻结构提供图文依据；整本的电子购买不等于允许把所有图复制进本地教学应用。若未来取得章节，应先按具体页／图号核对，再分别记录图文支持的解剖关系和原网格的人工审阅结论，不从书名或目录直接确认某段就是某节神经。当前原模型与候选身份状态均未改变。
