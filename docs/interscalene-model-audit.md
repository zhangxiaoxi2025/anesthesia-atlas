# 肌间沟区域源模型审计与导出

审计／导出日期：2026-10-24。范围为本地固定FBX的网格资产；没有改动App、组件、CSS、既有47份腋路几何或其manifest，没有运行解剖仓库附带脚本，也没有重建姿态或新增神经连线。本轮未新增下载。

## 结论与可用范围

已导出35个源网格：13个神经段、7块肌肉、3条动脉、3条静脉、9个骨性结构。几何JSON合计2,698,920 bytes、62,662个三角形。右侧前／中斜角肌、胸锁乳突肌、主要颈部血管、C3–C7与T1椎骨均有独立源网格，可用来观察源中立位的颈部走行和局部几何截面。

神经的关键缺口仍然存在：源文件只提供`Roots_of_brachial_plexusr`这一未分节近端合并网格，另有独立上、中、下干及其前／后股。不能把合并网格拆成臆定C5/C6/C7，也不能把其7个拓扑连通分量解释为7个已识别神经节段。固定源712个神经系统mesh名称中未找到可独立识别的C5/C6/C7名称或膈神经名称；因此没有生成或替补这些结构。

临床常说的臂丛“根”指形成臂丛的脊神经前支／腹侧支，与椎管内脊神经前根、后根不是同一结构。本资产保留`Roots of brachial plexus`作为源名称证据，界面建议称“臂丛近端合并网格（未分节）”。源内另有跨多个节段的`Anterior_root_of_spinal_nerver`、`Posterior_root_of_spinal_nerver`等网格；本次未用这些网格替代逐节腹侧支。

## 源几何与连续性检查

每个mesh只应用其原始FBX `matrixWorld`，再以0.01均匀缩放把厘米转米。保留+Y向头侧、+Z向前、−X为患者右侧及原始中立位。只去重完全相同的位置＋法线元组，坐标序列化为8位小数；不做网格简化、裁切、配准、手工连接或体位变形。

FBX部分血管／神经／椎骨mesh有子mesh，`Box3.setFromObject(parent)`会把后代也计入包围盒。这里严格按每个mesh自身变换后的顶点计算bounds；不会把子分支、骨附着标记或全下游血管误算成该mesh本体。

位置焊接后的近端合并网格有7个连通分量；上、中、下干各为1个。源近端网格到三干的最小顶点距离分别约0.345、0.151、0.160 mm。这是所导出表面的顶点采样距离，不是精确表面间距，也不证明生物学连续、节段身份、完整性或临床解剖正确。不同源mesh没有被强行焊接。

近端合并网格bounds为min `[-0.05603828,1.43313372,-0.03515413]`、max `[-0.01310245,1.50481486,-0.00551593]` m；源hash为`d682b44671d16a32f908b67a2626c53cfb2360484839a71c0e4808160b92219d`。该数据与既有腋路模块中同源近端网格逐值一致。

## 局部几何参考面

默认水平面来自源坐标，参数为：

```json
{
  "center": [-0.038, 1.468, -0.012],
  "u": [0, 0, 1],
  "v": [1, 0, 0],
  "n": [0, 1, 0],
  "width": 0.10,
  "depth": 0.08
}
```

u正向为前方（屏幕右），v正向为从患者右侧朝内侧（二维显示向下），法线n向头侧，且u×v=n。默认右颈ROI为min `[-0.080,1.43,-0.070]`、max `[0.005,1.53,0.055]` m。建议在平面中绘制真实三角网格交线，保持前／后、内／外的源坐标解释；这只是图谱几何参考，不是经临床校准的超声扫描面，也不与并排论文声像作同病例配准。
