# 逐根臂丛标注需求与来源门槛（待实现）

日期：2026-10-27。用户要求在图谱中从椎间孔出口辨认每一根神经，再沿连续结构理解汇成干、分股及形成束。此文件为核查后的实现规格，不代表v0.4.4已发布；当前运行版仍为v0.4.3。

## 应表达的身份

1. 孔出口附近识别完整脊神经，并将它与后续脊神经前支区分。
2. 逐根前支使用完整名称：C5、C6、C7、C8、T1脊神经前支（臂丛根），不统称臂丛干，不与椎管内前根混同。
3. 出口同时列出相邻骨：C5→C4–5孔，C6→C5–6孔，C7→C6–7孔，C8→C7–T1孔，T1→T1–2孔。出口层次不能被解释成源Y水平面、脊髓节段高度或实际探头高度。
4. 沿典型组成显示：C5+C6→上干，C7→中干，C8+T1→下干；各干前/后股共六股；上中干前股→外侧束，下干前股→内侧束，三干后股→后束。根、干、股、束、支分别显示。

## 三维可接受依据

- 每个标签有可追溯源对象/独立节段身份、明确作者/版本/许可；来源的几何和骨、肌、血管处于一致可核的坐标或有真实配准依据。
- 每根能从已核孔出口连续追踪到汇合；孔口和根干连接的确认不能仅由高度、圆圈排序或最短距离推断。
- 可以原样引用具这些标签的机构在线图谱，但平台查看/嵌入权不能被当作离线复制网格许可。
- 同一平面相交时只显示本面实际有的结构；与独立超声之间保持各自方向、未配准边界，不能按3个圆自动C5/C6/C7命名。
- 悬停/点选显示中文名、出口、汇合去向及来源，外置标签不遮盖；原始模型若缺失身份，应明确缺口。

## 当前判定

固定Z-Anatomy原FBX只有合并近端根对象，三干六股后束有独立身份；没有逐根前支，也没有具名外侧束/内侧束本体。当前运行模型不满足逐根标注门槛。不能把概念关系图或详细文字清单宣称为已完成逐根三维标注。
