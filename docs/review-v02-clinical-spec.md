## 4. 姿态审计必须保留的限制

`pose-audit.md`报告默认神经血管ROI共448个截线采样点，Jacobian约1.0000–1.0176、采样点对距离比约1.0000–1.00943。这只能说明默认局部参考关系基本被连续映射保留，不能证明它等于外展位患者真实神经血管关系。

同一审计也报告非ROI组织明显压缩/扩张，整体采样Jacobian约0.2063–17.3491，完整神经部分边长变化显著，肩胛骨与锁骨没有实现完整肩带运动。肌腱附着、软组织滑动、神经张力和筋膜约束没有验证。这些缺口有实质临床意义，不能因为默认ROI近刚体、有限采样Jacobian为正或源神经保持连通，就声称“经过验证的敬礼位解剖”。

当前界面持续显示“软组织形态待临床审阅”，模型来源对话框说明连续变形场、未验证肩带/滑动和估计皮肤偏移，且可切回原中立位。这足以维持**本地软件审阅候选**的限定身份；不支持将此候选直接改称临床完成版，或将过渡组织用于精确解剖测量、神经牵拉判断、针道/给药定位。

探头位置采用参考偏移而非已确认皮肤接触，已在可见探头说明与来源对话框披露。不得把探头外形与表面接近的视觉效果重新解释成已标定接触。

## 5. 冻结后仍由临床审阅者承担的具体判断

1. 对敬礼位重建逐结构核对：肩带、胸肌/肱二头肌过渡、肌腱附着和四神经血管连续性；必要时回到中立位比较，不能只看默认ROI。
2. 核对选定US图中四神经标签的教学可辨性、原图箭头保留后的解读，以及低像素裁图放大时的可用边界。
3. 对照实际常用摆位，确认本版“体位—探头短轴—声像—三维—功能”的解释顺序是否便于临床教学；可增加经核对的肌肉/联合腱标注，但未显示结构不得补猜。
4. 原版感觉与运动图继续保留指端、肌皮—前臂外侧皮神经、前臂内侧皮支、近端已分支、肋间臂/腋神经等边界；教学审阅不由工程PASS替代。
