# v0.8.3 原声像结构清单对照

2026-10-31。用户认可v0.8.2方向，要求二维包含的肌肉血管与左侧声像一致，三维以对应结构为主。

## 对照范围

左侧沿用Kumar Figure1B未改像素、未镜像，作者已标C5/C6/C7、ASM、MSM、SCM、VA。因此默认对照清单为C5/C6/C7、前斜角肌、中斜角肌、胸锁乳突肌、椎动脉，共7项。模型固定面的所有真实交线先按这7项筛选，二维与抽出副本显示相同清单；不再混入未在原图逐项标注的后斜角肌、肩胛舌骨肌、颈长肌、颈总动脉、静脉、骨、其他神经等。

这里的“一致”是有明确原作者标签的结构名称清单一致，**不是像素分割、精确形状、数量或空间位置已与超声配准**。原超声中未标名轮廓不据此认定不存在，更不强行命名。原图绿箭头所指区域未独立标注为具体骨部件，不为它补造对应骨名。

三维默认只显示7个主体对象；可选“显示邻近三维背景（原图未逐项标注）”显示周围模型背景，二维仍为7项。源对象仍保留以供骨性参照及原始图谱使用，没有删除原数据。

左侧增加ASM/MSM/SCM/VA四个外置中文交互标签，引线锚定原作者缩写文字附近；只是标签中心的显示锚点，不是肌肉边界、神经分割、病例三维对应或注药靶点。原C5/C6/C7原锚点保留。点击7项的选择栏、原图标签、二维/副本标签，均联动同名对象。固定面JSON与v0.8.2打包文件逐字节相同。

## 证据

69/69软件测试通过，新增约束7项范围、作者标签ID及真实交线均完整；既有源不变性、固定面方向和几何检查继续通过。常规构建、离线构建、verify-offline通过；Three.js大分块警告仍属体积提示。

对打包单文件经本机静态HTTP服务执行Chromium操作：选择7项、从原超声选ASM、从抽出副本选VA，以及背景开关，共10项采样；原图target与选择一致，副本高亮一致，副本结构ID始终恰为7项，固定面中心/法线不变；默认三维visible ID恰为7项，打开背景后三维结构数增多而副本仍为7。页面错误为空。390px窄屏无页面水平溢出，副本7项名称保留。见browser-v083.json；截图preview-v083-comparison.png、preview-v083-seven.png、preview-v083-mobile.png。
