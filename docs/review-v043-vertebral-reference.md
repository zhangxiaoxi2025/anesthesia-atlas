## 不得混同的身份

- `vertebra-c3`至`vertebra-c7`、`vertebra-t1`分别表示清单中完整源椎骨；多个本面轮廓仍归同一源骨身份，不凭轮廓称椎体、横突前结节、后结节或椎间隙。
- `brachial-roots`仍为源对象`680949521 / Roots_of_brachial_plexusr`的近端合并网格，未分出C5/C6/C7前支。骨性层次不能为其中的某条截线补出神经节段身份。
- `sliceFrame(level)`为模型中立位下的固定法线水平面。它与骨的相交结果不是经临床标定的探头扫描层面，更不是对应病例超声的空间配准。
- 当前`sourceSections`先对源网格真实三角面求交，再按`SLICE_SIZE`局部矩形裁切。若骨性导航继续消费这个结果，界面相交口径应明确为**当前局部切面与源骨网格相交**，不能声称无限水平面穿过的全部椎骨。

## 本轮发现及关闭项

1. **C5“更接近”措辞可能被误解为结节间距。** 原教学卡说“C5的前、后结节通常更接近”，与ASRA的similar size characteristics不够准确。已改为“向头侧观察C5时，前、后结节的大小通常较接近”，最终复读确认。
2. **独立小窗hover可能被主图隐藏状态抢回。** 初版Scene对任何隐藏图层hover都会清空；新增小窗在主图bone关闭时仍是可见独立层。已限制为主图自主拾取清除，外部linked hover不被主图关闭规则抹除。隐藏主图仍不显示或命中骨，最终复读确认。
3. **小窗缺少独立层说明和失败态接线。** 已增加“独立骨性定位层”，组件接收error并区分源加载失败；最后确认Module唯一调用传入`error={loadError}`。本项关闭不代表亲自复现了网络故障。
