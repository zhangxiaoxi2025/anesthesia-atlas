## 1. 实际来源与锚点

现有47个JSON只有positions、normals、indices。原始五个FBX经官方Three FBXLoader只读检查，SkinnedMesh、Bone节点、skinIndex／skinWeight、morph和动画片段均为0。本次没有将其冒充已有生物力学绑定，也没有执行任何上游模型仓库脚本。

坐标单位为米，Y向上、Z向前、X负为人体右侧。锚点从既有骨网格提取，属于工程几何锚点，不能当作影像标定的真实关节中心。

## 2. 形变方法与约束

所有神经、血管、肌肉和体表点使用同一个连续空间映射，依次经历肘部局部平滑旋转流、肩外展旋转流、上臂轴向渐变外旋。过渡使用smoothstep，旋转流采用20步RK4积分。全程没有按结构分别拖动神经、血管或肌肉，也没有只移动骨头而留下软组织不动。

肘场额外限制其近端／内侧支持域，避免将远处胸前组织当成前臂一起屈曲。上臂大部分区域使用精确刚体旋转；过渡带才进行积分。肱骨作为刚体随肩运动，桡尺骨作为刚体随肩、肘运动。肩胛骨和锁骨保留源位置；因此本版**未重现肩胛肱骨节律和完整肩带运动**。肌腱附着、软组织滑移、体积保持、神经张力和筋膜约束尚未验证。

原三角形indices完全保留，不新增连接，不补造神经。四条主神经源位置连通分量均为1，姿态后仍为1。这个拓扑结论不能证明源模型缺失的近端或分支已被补齐，也不能证明软组织形状正确。

`poseAnatomy(anatomy,'neutral'|'salute')`返回新结构及几何、重算bounds和poseMetadata，原数据不变。敬礼位normals交给渲染器依变形后几何重算。WeakMap缓存以源anatomy为键，首次计算后再次切换不重复运算。Node本机首次计算约0.9秒，不能据此推断所有设备性能。

## 3. 探头局部坐标与切面

`getProbeFrame(posedAnatomy,{station})`取station0为近端、1为远端，对应源Y=1.34→1.27m。默认station0.64对应源Y=1.2952m。在源动脉网格的实际截线上定位中心，保留来源段名“肱动脉”；不将其改名为腋动脉。随后将中心和邻近中心线通过同一空间场映射，从映射后的中心线和参考深向建立正交frame：

- `n`：近端到远端的局部动脉长轴；
- `v`：远离探头的深向；
- `u`：屏幕横向，满足`u×v=n`；
- width=0.14m，depth=0.12m，均为教学显示范围。

默认敬礼位frame实测：

```text
center [-0.252440873, 1.390676098,-0.003996378]
u      [-0.100279213, 0.993704462, 0.049955192]
v      [ 0.214302576, 0.070601537,-0.974212415]
n      [-0.971606137,-0.086987728,-0.220033292]
```

此为斜置的几何短轴参考面；将该frame与姿态后的真实三角网格求交，可实现同一3D平面的结构对应。它不产生真实超声回声、组织压缩或患者配准。

默认位置原体表patch射线没有交点，表面参考改用源动脉中心向外40mm的参考偏移再经同一场映射。返回的`surfaceStatus='estimated-reference-surface-offset'`明确保留这一限制，不能将图中探头表示成已接触真实分割皮肤。源体表分区本来就有不封闭和缺失区域，未为满足探头外观而造一层“真实皮肤”。

## 4. 默认教学ROI与非ROI分开报告

**默认神经血管教学ROI基本处于近刚体区域，血管边缘仍有轻度过渡；不能说全部点严格位于零形变过渡带之外。** ROI定义为源Y=1.2922–1.2982m内，四主神经、肱动脉和肱静脉的实际截线点。这是工程对应区，不是已验证的临床超声扫描区。

本次在三个源层面采样448个唯一截线点，审计结果：

| 指标 | 默认神经血管ROI | 非ROI过渡组织 |
| --- | --- | --- |
| Jacobian行列式 | 1.0000–1.0176；P99=1.0150 | 1173个采样点：0.2063–17.3491；P99=3.8495 |
| ROI采样点对距离比 | 1.0000–1.00943；P99=1.00507 | 不宣称保长或生理形变 |
| 默认四神经—动脉对应中心距离比 | 1.000094–1.000250，即变化小于0.03% | 更近端station0的已存在神经对应中心距离最大增加约19%；肌皮神经在此源层面缺失 |
| 默认姿态后斜面 | 四目标神经均与同一参考平面相交 | 近端移扫时允许某条源神经不在切面，不能强制画入 |

Jacobian采样全部为正，没有在采样点发现局部折叠／反转；**有限采样不等于证明全空间无折叠，更不等于生理形变正确**。默认ROI相对坐标接近刚体，说明算法没有为了摆位任意拆散该局部神经血管关系；它不能验证来源解剖或临床摆位后的实际组织位移。

非ROI仍有明显非生理体积变化和边长变化。强压缩样本位于肱二头肌短头及部分体表过渡，强扩张样本位于胸大肌腹部。四条完整主干的源网格边长比范围约为：正中0.508–2.064、尺0.505–2.210、桡0.573–2.071、肌皮0.587–1.040。这些数值是表面网格局部边的形变指标，不能换算为真实神经牵拉或张力。**这些过渡形态不得用于组织力学、手术测量或定量进针指导。** 为避免用外观掩盖误差，本轮保留这些量化限制，未对个别神经重新拉线或移位。
