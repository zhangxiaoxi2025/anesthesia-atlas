# v0.8.0 参考重建交付核验

日期：2026-10-31。用户本轮授权选择一个完整主体，其他来源补充，让整体便于解剖理解。采用固定Z-Anatomy骨、肌肉、血管主体，Open3DModel来源具名C5–T1与三干补充，共8个神经对象；整体刚体配准用于参考放置，未强行移动局部神经、焊接缺口或生成未知筋膜/膈神经。

## 行为

肌间沟主视图变为参考重建，原始同源视图可展开。点击前支直接选中其补充网格，不再只显示下游干；切面定位基点更新到所选网格高度中点，以实际斜面求交验证。八个补充神经的默认自动定位面均有真实交线。左侧保留Kumar作者原超声，按名称和典型汇干关系联动，不做病例空间配准。三维常驻标签为C5/C6/C7和上中下干，保留视野外提示。C8/T1可从选择栏查看，但原声像没有它们的独立作者标记。二维截线图外中文名及完整索引、角度调节、15秒抽离继续使用。

## 实际验证

- `npm test` 66/66通过；新增验证原源数据不被修改、合并后8个神经唯一且旧合并近端/旧神经不会竞争显示；八个神经所选斜面均实际相交。
- 常规构建、离线构建、verify-offline通过。Three.js体积警告约505KB，非构建错误。
- Chromium桌面1440×950、窄屏390×844：逐项点选C5/C6/C7和三干；DOM选中ID、名称卡、平面基点对应；抽离终点有原位面与副本；六个三维常驻名均保留。窄屏body scrollWidth为390。页面错误为空。
- 打包后的单文件另经本机静态HTTP服务重复上述验证，页面错误为空。日志browser-v080-checks.json及browser-v080-offline-checks.json，截图preview-v080-reference.png与preview-v080-mobile.png。当前未测试Finder直接双击、实体iPad、临床适宜性。
- source-integrity-v080.json逐项确认原110个public来源文件无变动；新增8个神经的派生数据在src/data/reconstructed-plexus.json（代码bundle直接内嵌，非远程加载），保留源名、配准矩阵、署名、许可；Blender导出脚本在research/open3dmodel-audit/export_teaching_reference.py。

## 不同数据层的证据

原主体Z网格身份与坐标保持。Open3D来源标签证明模型发布者的命名，不等于逐段临床认证；来源 root 对象范围及C5经C6近接后的分段仍需专业核对。先前配准的留出整骨中心误差约0.7/1.0mm，不能代表小神经误差；血管截短及局部截线差异仍在，报告位于research/open3dmodel-audit。界面持续显示“参考重建·待专业核对”和跨来源关系限制。该版本不称临床定位模型、不提供针道/注药/扩散。两本教材用于典型关系，未从商业书复制图像或宣称恢复精确三维坐标。
