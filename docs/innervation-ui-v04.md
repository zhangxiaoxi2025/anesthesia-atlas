# v0.4 功能支配面板：实现与检验记录

日期：2026-10-24。修改范围仅为 `src/components/InnervationPanel.jsx`、`src/innervation.css` 和本记录；未修改 App、旧 CoverageMap、医学数据或模型。医学清单来自 clinical_scope 编写的 `src/data/innervation-v4.json`。沿用 React 性能规范，静态小型 SVG 和逐项文字不引入额外数据请求或图像依赖。

## 接入

组件默认导出 `InnervationPanel`。props 为：

```jsx
<InnervationPanel
  selected={selected}
  onSelect={selectNerve}
  mode={coverage}
  setMode={setCoverage}
  blockType="axillary" // 或 interscalene
  onSources={optionalSourceCallback}
/>
```

根入口 import `src/innervation.css`。组件带自己的标题、四神经选择、感觉/运动切换、图例和来源入口，建议作为全宽板块替代旧的窄版 CoverageMap 小卡。`selected/onSelect` 和 `mode/setMode` 为受控状态；`onSources` 可选，接收当前神经 sourceIds。无该 callback 时仍可展开组件内正式来源链接。

## 感觉页的表达

- 默认前/后两面显示同一右上肢，从上臂到前臂、手全部保留；后视图按同侧方向镜像，拇指位于另一边。不是将左右上肢并排混用。
- 默认“四神经总览”：所选加深、其他三神经淡色，保证开始选择正中神经时仍能看到桡神经的上臂/前臂及肌皮的前臂区域。可切为“仅所选神经”。
- 支持“全上肢”与“手部放大”。后者使用相同 SVG 概念分区的局部 viewBox，没有创造新皮区；肌皮神经放大手部时有明确无手部主要皮区提示。
- 正中、尺的图形路径仅放在手部，没有给前臂/上臂补色。正中远端指背/甲床与桡神经近端指背分开；不是把整个手背涂成桡神经。
- 桡神经分四个 regionKey：后上臂、下外侧上臂、后前臂、背桡侧手。后前臂是概念带状区，没有涂满前臂前面；下外侧上臂与肩部腋神经范围分开。
- 肌皮神经显示前外侧及后外侧前臂，停在腕部附近，不延伸到上臂外侧或拇指/手掌。
- 其他皮神经用中性色底和独立清单说明，包括腋神经皮支、上臂内侧皮、前臂内侧皮、肋间臂、锁骨上神经。灰色不表示没有感觉或阻滞失败。未给这些其他皮支虚构精确皮肤边界。

SVG 为本地手工写的宽泛概念形状，没有 AI 解剖图片、教材图描摹、生成神经网格或患者皮区测量。它明确标记“概念示意 · 非阻滞预测”，不是皮节图，也不表示深部关节/筋膜感觉或手术麻醉范围。

## 运动页的表达

逐肌肉/肌头、动作、分支、层面与文献链接显示，完全取医学 JSON；不再使用任意肌肉色团。四终末神经目前为 46 条支配条目（正中 12、尺 17、桡 14、肌皮 3），其中部分按肌头/肌腹拆分，不能把条目数误称为 46 块独立肌肉。

另有“肩部与肩带”折叠列表，呈现 8 组神经、14 条肌肉条目，涵盖数据中列出的腋、肩胛上、肩胛下、胸背、胸内/外侧、胸长、肩胛背和锁骨下肌神经。它是补充清单，未宣称已收录每种个体变异或所有肩部神经。

每条仍显示 `levelNote`；肱肌双支配、拇短屈肌分头/交通和桡侧腕短伸肌分支等变异按医学数据保留。`blockType` 只切换该入路的限制说明，不把神经本体支配改画成阻滞成功图；近端已经离开的皮支/肌支不能从远端变化反推覆盖。

## 来源与数据合同

UI 读取固定 `regionKey` 映射，但区域名字、分支、正文、层面说明、肌肉清单与正式 URL 均来自数据。未复制外站图片或引入新的素材授权。

只做了两项小范围交叉核查：

- [WVU 官方 Radial Nerve](https://anatomyresources.hsc.wvu.edu/nm_deficits/Radial_Nerve.html)列出后臂、后前臂和背外侧手，并区分指端；该页只是本轮分区交叉核对，不采用其中其他笼统损伤推断。
- [NCBI Bookshelf NBK534840](https://www.ncbi.nlm.nih.gov/books/NBK534840/)列出上臂后皮、上臂下外侧皮、前臂后皮及桡浅支，用于确认不应只显示手背。完整临床依据和逐肌肉核对由独立医学任务记录，UI 没有另行扩大文献检索。
