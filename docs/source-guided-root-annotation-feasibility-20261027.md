# 可靠图文指导原网格神经分段标注：只读可行性评估

日期：2026-10-27。范围：现有固定源原几何、已知骨／三干身份与既有源审计。没有修改网格、源名称、界面、代码或当前 manifest；没有制作或发布 C5–T1 标签。未新增医学网络检索；以下为几何与标注流程评估，外部图文的临床适用性由另行来源审阅确认。

## 判断

**原则上可以用可靠二维图谱／文字指导人工标注现有三维网格。原作者没有逐根名称，仅说明不能直接继承该身份；不意味着经过逐段追踪、跨视图证据和专家审阅之后永远不能标。当前具备开展一个小型候选标注试点的条件，尚不具备直接自动给出全部 C5–T1 的条件。**

标注和重建需要分开：可以在不移动任何源顶点、不添加神经、不强行焊接的情况下，用独立的三角面／顶点索引掩膜、源坐标锚点和人工审阅记录标识某段已有表面。即使原来是同一个具名对象，也可以建立可追溯的局部语义标注。前提是该段在现有几何上能够稳定定位，而且其身份得到证据支持；不能照一张二维示意图把规范的五根顺序硬套到七个分量。

可靠图文可以提供结构关系、应核对的出口／分支、正常及变异模式和名称定义；它不能单独证明本图谱每一段表面的具体身份，也不能把图中的二维坐标直接配准到当前三维坐标。本文没有否定人工标注，而是把“几何候选”“来源辅助推断”“专家核定身份”分为不同状态。

## 骨性出口提供的证据和当前不足

当前模块含独立具名完整骨网格 C3、C4、C5、C6、C7、T1，均与神经及三干来自同一个固定坐标系。这比只用二维图或孤立神经线更适合人工核对：可以在侧面、斜面、前／后视中查看候选段相对于连续椎骨、孔周边界和相邻走行的关系。整体骨身份能够作为标注证据的一部分。

但目前**没有完成逐条候选神经穿过哪个真实骨性出口的表面追踪审阅**。全骨 Y 包围盒、质心、单一水平切面、最近骨距离都不能替代这一步；完整椎骨的各突起具有重叠高度，一段神经的三维走行也不等于某一水平高度。不能把之前的“局部切面经过 C6”直接转成“此圈就是 C6 前支”。

骨源清单中的 `Intervertebral_foramenj`（`FBX:219421163`）、前横突结节 `.j`（`192681259`）与后横突结节 `.j`（`769023778`）各仅有 36 个 loader 顶点条目，是通用辅助对象，没有逐椎／左右侧的出口语义掩膜。**这不意味着完整骨形态上一定不存在可辨出口；它意味着当前没有可直接继承的、已验证的逐孔分区。**人工可以在完整骨几何上核对和另行记录局部证据，但必须如实标为人工证据标注。

T2 当前没有纳入 35 个模块结构，属于“尚未选用”，不是固定源彻底缺失：同源 skeletal inventory 存在 `Vertebra_T2`，`FBX:825046538`，6,426 个 loader 顶点条目。若试点需要核对 T1／T2 相邻骨性窗口或最尾端候选走行，可以在相应实施范围内补入这个原始骨对象；本轮没有导出它。只补 T2 仍不会补出具名 T1／T2 神经，也不会自动消除近端走行歧义。相反，如果不补下界骨参照，就不能把尾端候选的出口核对视为已经完整；应把受此影响的段保留为未知。

还需要核实神经源的内侧端是否真正显示到可判定出口的范围。如果表面在出口外已截断、穿骨、互相重叠，或骨／神经精细形态不足以区分，增加图文和标准关系也不能制造缺失证据。

## 最小可审阅标注试点

建议只做“一条已有表面的出口→近端走行→具名中干”的证据试点，先选上述 **G5 几何候选**；暂称“中干近端候选段”，不先预设 C5–T1 名称。选择它的原因是与中干的几何邻接较清楚、与其余两干距离较大，便于暴露追踪与审阅方法是否成立；不是因为已经认定某根。

试点应形成以下小型审阅包，先评估证据，身份核定后才考虑应用标签：

1. **固定对象和局部掩膜。**记录源提交、FBX ID、几何 hash、精确源三角面／顶点索引与候选边界。保留原顶点、原拓扑和原坐标；人工标注单独存放，身份状态为 `candidate`，不是改写源作者名称。
2. **跨视图追踪。**用同一源模型至少提供两个互相补充的斜／侧视和一个与候选出口相交的局部切面，完整显示内侧端、孔周骨界、候选段及中干近端。每一张图的选中表面应指向同一份掩膜，而不是在不同图上另画近似黄线。记录可追踪与不可追踪的区间，不以美观掩盖断点。
3. **图文对应表。**逐条列出正式图谱／文章中的明确图号、页码／段落、左右侧和可比标志，说明其支持的是哪项关系；同时列出可能相似的邻近支、变异或其他解释。可靠二维图文在这里用于检验候选，不用于自动对号入座。
4. **独立人工复核。**建议由能辨认该区域的解剖／区域麻醉专业人员对原三维多视图逐段复核；若目标为长期教学使用，再由另一名独立人员核对争议段。软件或 AI 的一致同意不替代该专家审阅。每段允许“通过／需补证／无法判定”，记录审阅者、依据和边界。
5. **身份通过后再呈现。**只有出口与走行证据支持、相邻结构解释排除且专家接受的区间，才展示“人工核定的某前支／根段”；保留来源标签与人工标注的区别。未确认段保持原中性名称。随后才考虑把方法扩展到另一条路线，不能由一条通过推定全部通过。

无需为这一试点重新生成整条神经；也无需假定一个连通分量只能有一个语义标签。如果审阅发现同一连通表面跨越不同命名段，可用不改变几何的局部面索引分区；分区边界必须有可审阅证据，不能只是平均切成几份。

## 失败／暂停规则

- 仅能依赖标准“五根三干”的顺序、某干常见来源或单张二维图的相似外观，不能在原模型连续追踪：不赋节段名，结论为需补证。
- 候选的内侧端未显示到足够的骨性出口、所需上下界骨缺少，或只据骨包围盒／单层切面推断：该段保持未知；先补同源参考或改用更适合的资产。
- 需要移动、弯折、焊接、补线、切掉冲突表面才能符合图谱：停止这个“仅标注”试点；那已进入几何修订／重建，应另立任务与证据边界。
- 两个视角追踪到不同表面、存在可替代路线，或专家对出口／身份判断不一致：保存争议，不取多数自动压成确定标签。
- G1／G2 等附加分量不能解释，或在 G3／G4、G6／G7 的汇合处无法区分：可保留已经核定的局部段，不强制完成全套 C5–T1。
- 无法取得有足够细节、可合法引用的依据或合适人工复核：只能交付候选证据包，不能宣称已完成有临床教学可信度的逐根标注。

试点成功标准是“原几何不变、同一段可被复现定位、骨出口及远端关系可跨视图核对、身份审阅结果和不确定边界有记录”，不是“画面上终于出现五种颜色”。该评估支持进一步准备和审阅标注候选；本轮尚未完成任何一根的临床身份核定。
