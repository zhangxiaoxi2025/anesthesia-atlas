# v0.4.2 切面移动反馈：方向、单位与实现复核

日期：2026-10-26（Asia/Shanghai）。范围仅为既有模型参考切面的移动控制、源位置提示和展开动画状态；不新增医学事实，不重新检索，不改变模型或临床数据。实现审阅消息已收到，主线程在末节补记最终状态；不称临床认证。

## 坐标与单位

`sliceFrame(level)` 的中心为 `[-0.038, level, -0.012]`，法线 `n=[0,1,0]`；源坐标 +Y 指头侧，Y减小指足侧。`sourceSections` 以这个frame求交；Scene每次render把sourcePlane放到同一frame中心。原控件确实改变平面和截线，不是无效输入。

默认参考面Y=1.468 m。相对位移应使用 `(level - 1.468) × 1000` mm；当前范围1.435–1.505 m对应−33至+37 mm，步长0.001 m对应1 mm。左足侧/低Y，右头侧/高Y与滑杆数值递增一致。

这些毫米数是**相对默认模型参考面**的源坐标差，不是患者探头深度、进针深度、临床安全距离或独立神经节段定位。相机旋转后屏幕方向可以改变，解剖方向仍按源+Y头侧解释；不能把滑杆左右套到真实US左右。

## 旧实现为何容易看不出移动

以下为基于旧代码的静态解释，没有把它说成对用户屏幕的直接观察：

1. 控件放在动画卡片下方的结构区，视觉焦点与3D源位置分离；名称“模型水平面”及绝对Y米值没有直接说明向头/足侧移动。
2. 绿色sourcePlane面仅0.16透明度，嵌在多个透明身体网格中；缺少明显源位置读数或导轨。
3. progress>0时截线纸面已经抽出并转向屏幕，继续改level而保持该progress，容易把更换解剖层面误认为只在改二维纸片。
4. progress=0时sourcePlane与extracted白底共面，白底原先始终可见、透明度0.97且后绘制；可掩盖绿色源面。仅把progress设0而不处理该白底遮挡可能仍不够明显。

## 状态与验收口径

- 移动切面时暂停播放，回progress=0，清除旧hover；源身体和相机不随level追移，让切面相对身体的变化可见。
- 主要控件贴近3D；名称直接说明“切面上下移动”，同时标足侧/头侧和相对默认面的有符号毫米数。默认、正负位移及源Y读数应一致。
- 源位置阶段必须能看清源平面/边框/位置标记；抽出的白底不应在progress0覆盖源定位信息。位置引线应指真实frame角点或中心，不能假装标记某神经根或解剖靶点。
- 展开动画从当前level开始；level改变后的2D截线、中文归属和源平面保持同一平面，选中结构身份可以保留。离开该层面时继续显示“未相交”，不搬动结构凑同帧。
- 右侧真实US仍是独立静态参照，不因level自动换成某个病例层面；不把这些控制称为实时超声、探头深度或临床定位。
- 新增图形导轨/角标仅是显示辅助，不进入源结构清单、解剖hover或来源身份，不作为可注药空间。
