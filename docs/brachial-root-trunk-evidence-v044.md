## 1. 结论及逐节出口

典型解剖下，下表出口对应关系正确。表中为**脊神经离开椎管的椎间孔层次**，不是脊髓节段高度、水平切面坐标、骨网格相交结果或临床探头层面。

| 脊神经编号 | 椎间孔出口 | 臂丛贡献的标注 |
| --- | --- | --- |
| C5 | C4–C5椎间孔 | C5脊神经前支（臂丛根） |
| C6 | C5–C6椎间孔 | C6脊神经前支（臂丛根） |
| C7 | C6–C7椎间孔 | C7脊神经前支（臂丛根） |
| C8 | C7–T1椎间孔 | C8脊神经前支（臂丛根） |
| T1 | T1–T2椎间孔 | T1脊神经前支（臂丛根） |

出口表按来源S1的编号规则逐项展开：C3–C7延续C2在同名椎骨上方的出口次序；C8位于C7与T1之间；胸神经在同名椎骨与其下一椎骨之间。T1的出口因此需要T1、T2两个骨性标志，现有资产若未纳入T2，不应以屏幕边缘或任意一点代替经核定的T1–T2孔。

## 2. 必须区分的“根”和“支”

适合产品的基本链为：

**脊髓前根＋后根 → 混合性脊神经 → 脊神经前支／后支；其中C5–T1前支典型构成臂丛的五个根。**

- 臂丛教材所称的“根”是脊神经前支，不是椎管内的脊髓前根。前支承载感觉与运动纤维，不能将“前支”解释成纯运动神经。
- “脊髓后根”“脊神经后支”和“臂丛后股”是不同层级的结构；同样，“脊髓前根”“脊神经前支”和“臂丛前股”也不能互作别名。
- 若逐段展示，孔口附近标“C5脊神经（C4–C5孔出口）”，在已确认的前支段标“C5脊神经前支（臂丛根）”；不能把一条未经分段核实的网格同时当作上述所有段。

S1说明前根为运动纤维、后根为感觉纤维以及周围神经的感觉/运动纤维重组；S2明确臂丛根来自脊神经前支。上述中文链是对两项教材定义的组织，不是对当前源几何连续性作出的实测判断。

## 3. 典型根—干—股—束关系

以下关系由S2 Learning Objective 3后的两个正文段落直接支持：

| 上游 | 下游 |
| --- | --- |
| C5＋C6前支 | 上干 |
| C7前支 | 中干 |
| C8＋T1前支 | 下干 |
| 每一干 | 各分为前股、后股，共六股 |
| 上干前股＋中干前股 | 外侧束 |
| 下干前股 | 续为内侧束 |
| 上、中、下三干后股 | 合为后束 |

界面可用“**五根、三干、六股、三束，再到分支**”帮助理解；需把这张关系图标为典型组成。它表达纤维汇合和重组，不能被理解成每个病例、每个网格都具有完全相同形态或已证实的表面连接。

用户的“前中枢”不是此体系中的标准节点名称，可能是在口语中指前后股或某一束。需求记录应保留其原意待确认，不能擅自将它固定解释成“前股＋中干”或某个“中束”。标准教学层级为根、干、股、束、支；束的三个名称为外侧束、内侧束、后束，没有标准“中束”。
