# 腋路臂丛教学首版验收表

版本：0.1；日期：2026-10-23。状态：验收设计已拟定，实际页面与临床内容待独立复核。

## 授权范围与完成标准

- 当前执行范围是用户选择 B 后批准的本地腋路模块：真实来源的三维解剖、模型横断面、神经选择与文献支持的教学覆盖信息。可补充已经批准范围内的公开可复用资产。
- 本地构建、浏览器操作测试、数据完整性与文献一致性检查是本次可以记录的结果。它们不等同于临床认证、患者个体预测、临床操作考核或作者对公开教学发布的最终批准。
- 不把任意网格剖切称为超声。没有配准的体影像时，横断面必须标为“模型横断面”或“解剖示意切面”。
- 不把展示用注药区域或神经高亮称为药液扩散模拟；没有患者模型、药代与实验验证时，不输出精确临床扩散或成功率。
- 每一项测试只能在取得对应证据后标为 PASS。缺失或无法观察记为 NOT VERIFIED；已发现反例记为 FAIL；不得用构建成功替代临床或视觉验收。

## 已独立发现的资产限制

1. human-atlas 固定提交 `1c38bf35c254a891200d3cedecfd57abebe83d8d` 的 `public/models/atlas.json` 为 BodyParts3D 4.0，含 2,234 parts、3,432 concepts、139 nervous parts。实际 parts 与 concepts 均未找到正中神经、尺神经、桡神经、肌皮神经或臂丛。不能把这份清单的“有神经系统”解释为腋路目标神经齐全。
2. 可追溯的血管/肌骨结构存在。例如右腋动脉 `FJ2268 / FMA22655`，右腋静脉 `FJ2269 / FMA13330`，右喙肱肌 `FJ1488 / FMA37665`。概念可能包含多个网格，不能把概念数当成独立网格数。
3. Z-Anatomy 上游固定提交 `6c7f9016bd5899ac8edafd31b9900c151df42ed6` 的 `Resources/Models/FBX/NervousSystem100.fbx`（53,887,724 bytes；Git blob `4ec6e3cb2a1ba821aca02c1d523ac614fdf41a02`）通过 HTTP Range 元数据独立确认存在 `Musculocutaneous nerve.r/l`、`Radial nerve.r/l`、`Ulnar nerve.r/l`、`Median nerve.r/l` 的 Model/Mesh 节点。节点名称存在只通过了来源候选门槛；它不证明导出后几何完整、位置正确或与其他来源已配准。
4. Z 上述 FBX 的四神经有非零局部平移、约 -90° 的 X 轴局部旋转，不能跳过节点变换只提取原始 Geometry 顶点。与 human-atlas 的几何合并前，必须检验坐标、比例、姿势与同名标志点。若不能注册，优先采用同源局部结构，不以手工随意拖拽掩盖误差。

## 阻断性检查

下列任一项失败，就不能把首版描述为“完整真实腋路神经解剖教学模块”。界面与知识层可继续开发，但必须明确显示缺口。

| ID | 场景与操作 | 必须观察到的结果 | 证据方式 |
| --- | --- | --- | --- |
| A01 | 查询四目标神经的交付资产 | 每条神经均映射到实际几何，含原名、来源仓库、固定提交、原对象标识、导出方法与本地校验值；不存在用任意黄线冒充源模型的情形 | 交付 manifest 与几何数值检查 |
| A02 | 启动右侧腋路视图，逐条选择正中、尺、桡、肌皮神经 | 只选中相应右侧神经；名称、颜色、详情与实际几何一致，左右侧不混淆，四条均可见或能一键定位 | 浏览器操作与截图 |
| A03 | 检查四神经、腋动静脉、喙肱肌、肱二/三头肌、肱骨的相对位置 | 三维空间共用可解释坐标与姿势；没有明显错位、比例错误、对侧穿越或把近端/远端截段误当目标 | 三个不同方向截图；麻醉解剖逐结构复核 |
| A04 | 将默认视角与任一相反方向视角对照 | 稳定显示所用侧别、近远端、内外侧/前后方向及观察方向；不能依赖屏幕左右来暗示解剖左右 | 浏览器截图与方向标签对照 |
| A05 | 展示注药区域或靶点信息 | 区域明确是教学示意；不把神经内部或血管腔当正常靶点，不显示未验证的精确扩散、容量或阻滞成功判断 | 内容逐条复核与截图 |
| A06 | 打开全部神经覆盖 | 页面区分皮肤感觉、运动作用及不完整覆盖，并明确这是典型解剖/教学范围；不将根性皮节、周围神经皮区及手术麻醉范围合并成一张确定图 | 临床文献与逐字段审查 |
| A07 | 检查横断面标题、图例与空白状态 | 一直可见“模型横断面/示意”语义；不得称为实际超声或个体切面。未相交结构不凭空画出 | 内容检查与浏览器截图 |

## 临床内容的独立复核项

此部分需等临床资料与 UI 字段冻结后进行。设计阶段的列项不是临床内容已通过。

- 四条目标神经的中文/英文名称、选择层级、近端/远端分支与手背/手掌方位正确。
- 单神经的典型皮区与运动作用分别表达；肌肉的运动支配不写成“肌肉皮肤的感觉区域”。图示边界明确为近似，处理皮区重叠与变异。
- 与腋路层面有关的典型局限单列，例如上臂内侧皮肤、止血带相关问题及近端分支的边界；不因“臂丛”三个字便把全部上肢都涂成保证覆盖。
- 肌皮神经与喙肱肌的关系、其可能需要独立辨认的教学信息有可追溯依据；位置变化不能用固定钟点位置作保证。
- 腋动脉与腋静脉可区分；多支静脉或解剖变异如未建模，应注明参考模型局限。
- 若提供注药示意，只说明受文献支持的空间概念与目标外周关系；临床剂量、针尖安全判断、完整操作步骤与成功率不能由几何高亮推演。
- 资料来源既区分资产许可与医学证据，也区分可阅读与可复制图片/超声素材的授权。
