# 现成腋路敬礼位三维资源：只读核查

核查日期：2026-10-23。当前用户要求是使用有来源的既有体位资源，不再自行将中立位模型变形成敬礼位。本轮只搜索、阅读官网/作者论文以及访问公开演示；没有修改 App、购买、登录新账户、联系作者、下载模型或抽取商业平台资源。

**结果：尚未找到同时经本轮核实的“原生腋路敬礼位 + 完整相关神经血管 + 可自由旋转 + 允许接入本工具”的现成资源。** 最接近的三个候选如下。它们是后续可要求提供具体场景演示/许可的对象，不是已经取得的替换模型。

## 来源与验证证据的分层

- **作者/机构可查**：ARiRA 作者、Primal 制作团队与 NYSORA 平台可查；仅有“专家制作”“medical grade”或课程 CPD，不能证明特定体位神经血管几何准确。
- **数据来源可查**：Primal 公布真实人体 CT/Visible Human 的总体制作流程；本轮没有查到其目标腋路姿态的独立供体/采集记录。ARiRA 与 NYSORA 的特定腋路几何来源未公开核实。
- **论文支持**：ARiRA 存在 2025 RAPM 会议摘要 [EP068](https://rapm.bmj.com/content/50/Suppl_1/A88.2)，检索内容为教学平台试用/问卷偏好，不是腋路敬礼位的几何准确性验证；正文访问返回 403，未以全文已读处理。没有把任何平台的满意度/学习效果论文当作体位几何认证。
- **可观看 / 可嵌入 / 可导出 / 可再分发** 是四种独立能力或权利。能看到 WebGL/iframe 不等于允许抓取资产；购买个人订阅不等于获准导出网格或离线封装。

## 本轮查过但未进入主要候选的方向

**RA-UK / e-SAFE**：实际读取 [RA-UK 教育资源](https://ra-uk.org/education/education-links)和 [e-SAFE 区域麻醉目录](https://e-safe-anaesthesia.org/e_library/09/index_09.html)。能找到腋路教程/课程，未核实其有独立、可导出的腋路敬礼位网格。RA-UK 发布 [ARiRA 尸体课程页面](https://ra-uk.org/courses/2026/arira-regional-anaesthesia-cadaver-course-4-dec-2026)，但课程刊登不等于 RA-UK 向我们授权 ARiRA 资产。

**Complete Anatomy / 厂商运动模型**：官方有肌肉运动、关节演示和一般三维旋转，未确认目标腋路敬礼场景。[Complete Anatomy](https://3d4medical.com/)、[官方条款](https://3d4medical.com/terms)。Primal 的 [Functional Anatomy](https://primalpictures.com/functional-anatomy/)也有厂商提供的运动场景，但“模型能动”不能证明目标体位的神经血管资源已经存在。用户已经明确不要自行摆姿或变形，因此不能通过这些泛用能力补成目标模型。

**大学/标本模型与 Sketchfab**：找到 [UBC Medicine Educational Media 的 Brachial Plexus](https://sketchfab.com/models/932dbecba80541ce9168cef085fc15fa/embed)，但主模型页返回 403，未核患者姿态/授权，不能认定可用。Sectra 官方[教学指南](https://resourcehub.epsectra.com/wp-content/uploads/2021/03/Anatomy-teaching-guide_2.0.pdf)列 Monash M019 Axilla and Thorax，属于标本库方向；没有据此确认完整肘部 90/90 姿态或可复用资产。这些不优于以上三个可继续核查的对象。

**商业模型市场**：CGTrader 卖家 HzA 的 Human Axilla Anatomy 自称来自实际标本扫描，但没有核实机构、供体采集、验证论文和目标 90/90 姿态，不能因“medical grade”“scan”营销词纳入已验证清单。未购买或下载。

## 下一步的明确通过条件

对 ARiRA 或 Primal 的任何后续演示，只核这一组具体条件：对方可直接打开其已经存在的 **axillary** 场景；完整展示肩约 90°外展/外旋、肘约 90°屈曲的既有体位；可旋转并显示正中、尺、桡、肌皮神经及相邻动静脉/肌肉；有清楚的制作来源和审核边界；合同明确允许我们的接入方式（外链、嵌入或资产导出分别确认）。若需我们自行变形或厂商另行新建，便不是本轮寻找的“现成资源”。

在上述条件未核实前，本次结论保留为 **NO_CONFIRMED_DROP_IN_SOURCED_SALUTE_3D_ASSET**。可以把真实、授权、来源可查的体位照片、超声和既有来源三维分别展示，不应继续用自行变形模型填补“已有临床体位模型”这个缺口。
