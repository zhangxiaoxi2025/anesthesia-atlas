## 风险规则与验收口径

| 风险 | 必须满足的规格 |
| --- | --- |
| 合并根的多个截圈被当成多个已知根 | 同一源ID的全部截线只归“臂丛近端合并网格（未分节）”。可用“本面轮廓1/2”等几何索引区别，不能命名C5/C6/C7、“第几根神经”或据圈数判定根数。 |
| 开截线/裁切分量被称为完整神经横断圈 | 使用“截线/本面轮廓/几何分量”表述；没有闭合证据不称完整横断面，几何分量数不等于神经数量。 |
| 椎骨多个截形被误当多个源结构或神经节段 | 同一椎骨的多个截形共享一个源名和ID；保留“第6颈椎”等全名，不能缩为孤立C6后与US根标签混淆，也不凭外观补称横突/椎板等未核分部。 |
| 用视图序号代替解剖身份 | 编号只表示本次显示索引，可能随层面、排序或过滤变化；不将其作为跨切面的固定追踪身份。源ID/中文名承担归属。 |
| 引线指空白或邻近错误结构 | 每个需要指认的几何分量至少有引线落在本结构真实可见截线上；不只用外接框中心指向空白。拥挤时可用一个外置源名/编号连接多条同源引线。 |
| 图层关闭或切面变化后仍留标签/命中 | 标签、命中区和hover高亮跟随当前可见图层及当前截线。已隐藏/离开本面的对象不能继续以悬浮标签指向另一轮廓；若保留所选名，需明确“未显示/未相交”。 |
| 三维悬停给出无来源的身份 | 命中对象只能返回该真实mesh的source身份；透明/裁切/隐藏处理不能使屏幕上不可见的结构抢占标签。标签应能核对中文名与源对象名/ID，不能从位置反推根节段。 |
| 3D/2D hover被误读为真实US配准 | 只联动同一源模型与该模型求交线。真实US继续是独立病例参照；不在其像素上生成对应点、针尖、神经内外判定或安全距离。 |
| 单条轮廓高亮被当成独立临床结构 | 可以强调某一几何分量帮助辨认，但同时保留其所属源结构；不能把该分量升级为新的命名神经/骨性分部。 |

## 实现复核状态

已读新增 `src/components/SectionLabels.jsx`、`src/section-label-utils.js` 与 `src/section-labels.css`，完成标签组件本身的静态检查：

- `shortSectionName` 对合并根专门返回“臂丛近端·未分节”；完整标题、aria标签和中文索引均使用源完整名称。颈椎保持“第6颈椎”等名称，没有孤立C6别名。
- 组件以源结构ID分组，所有几何分量共用该身份；每个分量单独绘线，数据属性分别保留source-id与几何component序号。
- `componentAnchor` 从该分量真实线段端点取锚点，不使用落在空白的外接框中心。
- `layoutSectionLabels` 在组件分组前过滤隐藏图层；条目、引线和索引共享同一过滤结果。
- 旁注明确编号随层面/图层变化、可能有窗口裁断的开截线、合并根未分节，以及模型图与声像未配准。

另外实际运行了一次仅计算、不改文件的默认切面检查（Y=1.468 m）：15个本面源结构形成18组几何截线；合并根、前斜角肌、第6颈椎各2分量且各有2条引线。关闭nerve和bone图层后，剩余标签中这两类的数量为0。该计算核实显示归属/过滤，不证明神经节段身份或临床准确性。

新的Scene及Module接线完成后，已补读最终 `InterscaleneModule.jsx`、`InterscaleneScene.jsx` 和更新后的 `SectionLabels.jsx`：

| 检查项 | 实现证据与结果 |
| --- | --- |
| 单一状态绑定真实源结构 | Module将同一selected/hoveredId传给Scene、内页标签和放大标签。名称来自manifest的name；Scene名称dock保留structure-id和原source-id。没有由屏幕位置新增解剖身份。 |

| 隐藏/切面变化后的hover | Module在level/layers变化后清hover；Scene拾取先过滤图层和局部裁切，并在hover对象被隐藏或提取截线消失时清除。隐藏图层不继续显示dock名称。 |

| 3D悬停与点击的含义 | 身体网格按最近有效命中，透明肌肉没有被神经类别优先绕过；拖拽与点击分开，取消/离开会清hover。名字仍属于实际mesh。 |

| 原始解剖与能力边界 | 仍明确合并根未分节、没有独立C5/C6/C7标签，不补膈神经，不更改源网格，也不产生针尖、安全空隙或注药定位。 |

## 本轮发现与关闭的P2

**问题：可见提取线与拾取身份的优先级不一致。** 初版提取线设为`depthTest:false`且在身体之后绘制，但拾取在较近body存在时优先返回body。屏幕重叠处可能出现“看见彩色截线，名称却属于另一前景mesh”的误导。该问题已同步给主线程与Scene实现代理。

**修复后复核：** 最终 `pickAt` 先核对真实line与真实纸面矩形的同时命中，返回该线所属source身份；没有line时，纸面空白按深度写入的前景body判断是否遮挡，不把纸面本身当结构。身体部分仍按最近可见且未被裁切的真实mesh命中，不因神经种类跳过肌肉。这个规则与当前提取图形层的显示优先一致，因此本项静态复核已关闭；实际指针呈现仍需浏览器检查。

## 剩余范围与状态

本次没有发现必须新命名神经节段或新建模型才能解决的标签缺口。原源身份可以诚实地保留多截线形态，且通过共用名称与多引线实现可读性。当前无未关闭P1/P2。若后续改变图层拾取、绘制遮挡顺序、根/骨别名、几何分量到source的映射或把hover扩至真实US，需针对改变重核。
