# v0.7 肌间沟参照平面与三维方向审阅

审阅日期：2026-10-31。范围：只读核对用户提供的教材、官方教学资料、现有模型坐标与切面代码；本文件不改源网格，不建立超声像素与模型的空间配准，也不核定近端神经根身份。

## 结论与应先修复的问题

- **P1：world-Y 恒高切面不能称为常用临床肌间沟超声平面。** 临床常用颈外侧横向探查会调节探头倾斜，目标是得到臂丛的短轴图；这可以是轴向斜切。现有实现只有 `Y=常数`，相机转正不会改变相交的三角面。应将“源模型横断参照”和“自选斜切参考”命名分开；后者改变平面基底并重算真实交线。
- **P1：书中 C5/C6/C7 标签不能转移到未分节源网格。** 书中图13-8的标注支持该图的识别；源对象只有合并近端网格。不能把某层出现的三个圈或 G1-G7 几何分量自动编号成 C5/C6/C7。已有源具名三干可以按源名显示。
- **P2：横断近景仍用整块颈至上臂 ROI 拟合，导致相机被推得过远。** `SourceSliceScene.jsx` 的 `poseFor()` 在 transverse 模式下仍用 `boxCorners(region)` 拟合。近景应只拟合当次平面矩形及小范围上下背景，整体视角再拟合完整 ROI。
- **P2：三维观察方向、切面方向和超声画面方向需各自可见。** 固定“右侧·中立位”不足以解释任意旋转后的三维；三维方位轴应随相机更新。切面轴跟随平面基底；原超声保留原方向和原图标记。

### 为什么当前默认层面不能靠相机转成教材图

原默认平面中心 `[-0.038,1.468,-0.012] m`，`u=+Z, v=+X, n=+Y`。它的画面左=后、右=前、上=外侧、下=内侧。因此ASM常在图右，与书134布局相反。

原始C7骨网格的最高Y为 `1.46552718 m`；本次真实三角相交复算确认，在 `Y=1.468 m` C7骨交线数为0。即使把相机旋转、放大，默认平面仍不可能出现该书中的C7横突切迹。降低到 `Y=1.455 m` 时C7骨可以相交，但这仍不证明切到教材的那个C7横突截面，更不证明根身份。

同一平面上，SCM与近端合并网格沿纯 `+X` 的平均截线深度接近；把“内侧”直接当“临床图像深部”并不能自然得到SCM浅表的布局。临床声束从皮肤进入的方向与源世界轴之间仍需可解释的局部参照。

## 建议的实现边界

1. **独立保留源横断参照。** 如需让其阅读方向更接近教材，可用 `u=-Z, v=+X, n=-Y`，仍满足 `u×v=n`。此时前在左、后在右、外侧在上、内侧在下；这只是同一恒Y平面的阅读方向改变，不称临床标定。
2. **自选斜切真实改变平面。** 用户可调画内旋转与头足倾角；共同变换 `u,v,n`，并重算源三角面交线。二维图、原位框、面内交线副本与相机使用同一frame。任何预置角度都称“显示起始角”，不说“教材精确角度”。
3. **保留相机朝向与画内深度的区别。** `n`是平面法线，`v`是切面画内向下方向，摄像机从 `center-distance*n` 看向平面，并使用 `up=-v`。超声中从浅到深的方向在平面内，不能把摄像机前进方向称为声束方向。
4. **原位切面常驻，副本缓慢分离。** 面向相机的一半源显示可临时裁显，以看到原位真实交线；源数据不改变。移出的线组是可追踪的显示副本，不将源解剖搬走。镜头先近景聚焦，再保持朝向并慢移副本；抽出后原位交线仍在。
5. **不同超声图保持独立方向。** 现有Kumar图在 `src/data/interscalene-ultrasound.json` 中记载MSM左、ASM右；书134相反。不能套一个固定“临床左/右”到两张原图，也不能静默镜像Kumar。界面可以明确显示每张原图的作者方向和模型自身方位。

## 腋窝三维图可用的方向标记

方向来自源坐标及当前相机，应在三维视口内显示，不能把2D图的方向条贴到3D视口上。

| 三维相机预设 | 合适文字 | 不应暗示 |
| --- | --- | --- |
| `front=[0,0,1]` | 前视；头侧↑、患者右←、患者左→ | 当前模型已外展或与原超声同视角 |
| `right=[-1,0,0]` | 右侧视；头侧↑、后←、前→ | 图像左右等同患者左右 |
| `oblique=[-.85,.22,1]` | 右前上斜视；配动态头/前/右方位轴 | 固定左右边框可以完整表示斜视 |
| 任意拖动 | 自由视角；动态头、足、前、后、患者右、患者左方向轴 | 上方一定头侧、左方一定外侧 |
| 当前腋窝源横断 `u=+X,v=-Z,n=+Y` | 右上臂源横断；前↑、后↓、外侧←、内侧→；从足侧看向头侧 | 是外展体位的腋路超声，或物理探头方向已标定 |

动态轴可把源方向向量投影到相机屏幕坐标后画成小型罗盘。轴接近观察方向时，用朝向/背向屏幕符号，避免不稳定箭头。平面倾斜时轴名称用“朝前/朝后/朝头侧”等投影意义，不把任意画内下方都标成“深部”。
